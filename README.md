# The Domčo Universe

A private-by-default, browser-only friendship scrapbook from Saurabh. Built with React, Vite and Tailwind CSS. No backend, account system, analytics, external fonts, music, or API calls. Nothing has been deployed.

## Run locally

Requires Node.js 20.19+ or 22.12+.

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. On Windows PowerShell, use `npm.cmd` if execution policy blocks `npm.ps1`.

## Make it personal

Edit **`src/content.js`**. This single file contains her name, your name, location, photo paths, image descriptions, captions, gallery notes, talent descriptions, adventure outcomes, quiz choices/results, encouragement messages, and final letter. Her preferred name is set to `Domčo`, as supplied in her message. Edit `name` and `greeting` together to change it. No shared memories have been invented.

All five supplied images are connected: `download.png` is the opening portrait, `3.png`, `2.png`, and `1.png` appear in the talent section and museum, and `4.png` is the chat screenshot in the museum. The lightbox shows all five complete images. To replace them:

1. Copy the original photos into `public/photos/`. Prefer compressed WebP or JPEG, roughly 1,200–1,600 pixels on the longest side.
2. Set each `photos` entry's `src` to `/photos/your-photo.webp` in `src/content.js`. Use the original photo rather than a screenshot of a chat when possible. Describe the actual image in `alt` and customize its label/note/caption.
3. All photo frames use `object-fit: contain` to preserve the complete image and avoid face cropping. The lightbox also shows the whole image. Fixed frame sizes prevent layout shifts.
4. Character `photo` values reference the photo array by index; reuse images or point each talent at the appropriate entry.

The local placeholder artwork is generated by `node scripts/create-placeholders.mjs` and can be deleted once replaced. It does not represent her actual appearance.

## Check and build

```sh
npm run check
npm run build
npm run preview
```

The production website is in `dist/`. `base: './'` supports hosting in a subdirectory. Serve the build over HTTP; do not open `dist/index.html` directly using `file://`.

Browser checks (after installing the Playwright Chromium browser if needed):

```sh
npx playwright test
```

Checks cover the celebration, each character, gallery notes, image viewer navigation and Escape/focus return, side quests, quiz replay, all encouragement messages, envelope, reduced motion, local assets and viewport overflow. The app uses native buttons and a native modal dialog; keyboard users can Tab between controls, Enter/Space to activate, and use Left/Right/Escape in the image viewer. Reduced-motion preferences disable confetti and transitions. All choices are temporary, stay in the browser, and reset on reload.
